<p align="center">挂机修仙传</p>

一款纯html网页版的挂机小游戏。

游戏大小仅64KB，游戏总时长3-5小时（看玩家运气），适合上班挂机摸鱼。

因为依赖浏览器页面活动进程，所以浏览器最小化或切换其他页面时无法运行，请保持游戏页面在前台。

存档文件在localStorage，存档名guajixiuxian_save，目前不支持导出导入存档。
